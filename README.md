<h1 align="center">YZ Translator · 划词翻译</h1>
<p align="center">读懂一个词，也读懂整句话。<br>离线 MDX 词典 · AI 句子解读 · 一键复制 Markdown 笔记</p>

浏览英文网页时，选中文字即可查词或翻译，无需来回切换词典与聊天窗口。查单词用自己的离线词典；读长句用自己选择的大模型，获得译文、表达拆解、句法与语气说明。

## 为什么用它？

| 功能 | 帮你做什么 |
| --- | --- |
| 鼠标旁的划词按钮 | 选中文本后立即操作，减少阅读中断 |
| 离线 MDX 查词 | 使用自己的词典，释义在侧栏完整展示，支持适配的 MDD 发音资源 |
| AI 句子解读 | 英文与译文对照展示，逐项解释表达、句法及语境语气 |
| 划词语音 | 选中文字生成语音，在侧栏试听、调速、下载 WAV；支持百炼千问与 OpenAI 兼容语音接口 |
| 流式输出 | 内容边生成边显示，保留打字机效果 |
| Markdown 笔记 | 一键复制原句、译文和解析，方便粘贴到笔记工具 |
| 本地历史 | 回看查词、翻译与已生成的语音，支持删除、清空和最大条数限制 |
| 自选模型 | 配置自己的 API 地址、API Key 与模型名 |

适合阅读英文社区、技术文章、产品文档，也适合把日常阅读积累成英语学习笔记。

## 快速安装

目前通过 Chrome 开发者模式安装，尚未发布到 Chrome 应用商店。需要 **Chrome 120+** 和 **Node.js 20.11+**。

```bash
git clone https://github.com/zhangyong3/yz-translator.git
cd yz-translator
npm ci
npm run build
```

1. 打开 `chrome://extensions`，启用右上角的「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择项目中的 **dist** 文件夹。
3. 将 YZ Translator 固定到工具栏，方便打开侧栏。

更新代码后重新执行 `npm run build`，再到扩展管理页点击重新加载。已有网页可能需要刷新，划词按钮才会使用新版本。

## 两步配置，开始阅读

在扩展管理页点击 YZ Translator 的「详情」→「扩展程序选项」，打开独立设置页。

### 1. 导入自己的词典

点击「选择词典目录」，选择包含 **一个 MDX 文件** 的文件夹。同目录的可选 CSS 与 MDD 文件会一同导入。

词典保存在扩展的 IndexedDB 中，查词在浏览器本地完成。原目录更新后需要重新导入。项目不附带词典，请使用有权使用的词典文件。仅使用查词功能时，无需配置模型。

### 2. 配置翻译模型

| 设置 | 填写方式 |
| --- | --- |
| API Base URL | 服务的接口根地址，例如 `https://api.openai.com/v1`，无需加 `/chat/completions` |
| API Key | 对应服务的密钥 |
| 模型名 | 服务支持的模型标识 |

保存设置时，允许扩展访问你填写的接口域名。服务需要兼容 **Chat Completions 的 SSE 流式响应**；接口只返回普通 JSON 时，整句翻译会提示错误。

### 可选：配置语音服务

在设置页的「语音服务」选择接口协议，填写独立的 Base URL、API Key、模型与默认音色。两个服务的配置分别保存，切换服务不会覆盖另一份配置。模型与音色支持手动填写，但必须属于对应接口协议；DeepSeek 的文本接口不能用于生成语音。

- **阿里云百炼**：默认地址 `https://dashscope.aliyuncs.com/api/v1`，模型 `qwen3-tts-flash`、音色 `Cherry`。当前适配 `qwen3-tts-` 非实时系列；`qwen3-tts-instruct-flash` 支持可选朗读指令。超过 600 字符按句子或空白分段生成，再合并为一个 WAV。保存时授权 API 域名及 `https://*.aliyuncs.com/*`，以下载服务返回的临时音频文件。地域地址与密钥须配套。
- **OpenAI 兼容语音接口**：填写接口根地址（如 `https://api.openai.com/v1`），服务须支持 `POST /audio/speech`、`model`、`voice`、`input` 和 `response_format: "wav"`。可使用兼容此协议的服务并手动填写模型。OpenAI 官方旧 TTS 模型已宣布于 2027-01-06 停用；Realtime API 需要另一个适配器，当前不支持。

语音功能不依赖翻译模型。其他协议（MiniMax 原生、ElevenLabs、CosyVoice、Qwen-Audio、Realtime）尚未适配；不能仅换一个模型名调用。

## 怎么用？

1. 在普通 HTTP(S) 网页选中一个词或一段英文。
2. 点击鼠标旁的查词图标，侧栏显示离线词典释义；也可以在「查词」页手动输入。
3. 点击翻译图标，侧栏逐步显示英文、中文译文和展开的解析条目。
4. 点击「复制 Markdown」，把本次解读保存到自己的笔记工具。
5. 在「历史」中重新打开记录、删除单条记录或清空全部记录。
6. 点击划词工具栏的喇叭，在「语音」侧栏自动生成原文音频。也可手动输入最多 1200 字符后生成。服务商、模型和音色仅在扩展程序选项中设置，侧栏自动使用已保存的配置。支持取消生成、播放/暂停、拖动进度、0.75–2× 播放速度与下载 WAV。点击重新生成会再次调用服务。

语音生成成功后，原文与完整音频按历史条数设置保存在本地 IndexedDB；历史设为 0 时不保存。打开语音历史直接载入已有音频，可再次试听、调速与下载，不重新调用服务；删除、清空或超出历史条数限制时，音频一同删除。音频会占用本地存储空间。

本次侧栏另有临时缓存（最多 6 条、合计最多 20 MiB）。相同文字与配置再次划词可复用已完成的缓存，不重复添加历史；重播、下载与播放调速不调用接口。关闭侧栏后临时缓存释放，已保存的历史保留。分段请求中途失败时，已完成的请求可能仍由服务计费。

历史默认最多保存 **100 条**，可在设置中调整为 **0–1000 条**；设置为 0 可关闭历史保存。来源页面标题和网址默认不记录，可按需启用。

## 数据与隐私

- **离线查词**：词典及查询在浏览器本地处理，不上传词典文件。
- **整句翻译**：点击翻译后，选中的文本发送到你配置的模型服务，适用该服务的隐私政策与计费规则。
- **生成语音**：点击喇叭或生成按钮后，文字、音色及适用的朗读指令发送到独立配置的语音服务；不发送来源页面标题和网址。请求与下载由扩展可信侧栏执行，密钥不传入网页内容脚本。
- **API Key 与历史**：保存在浏览器本地；API Key 仅扩展可信页面和后台可读取。本地浏览器存储不是系统钥匙串。
- **来源信息**：默认不保存页面标题与网址。

## 常见问题

**为什么某些页面没有划词按钮？**

当前支持普通 HTTP(S) 网页。Chrome 内部页、其他扩展页、`file://` 页面及浏览器限制内容脚本的页面不支持。画布、封闭 Shadow DOM 和浏览器自带 PDF 阅读器中的文字也可能无法识别。

**查不到词怎么办？**

确认已成功导入词典，再尝试在「查词」页输入单词原形。不同 MDX 词典的内容、样式和资源格式不同，部分词典可能存在兼容性差异。

**模型报错或没有输出？**

检查 Base URL、密钥和模型名，以及是否已授权接口域名。服务必须支持 `/chat/completions` 和 `stream: true` 的 SSE 输出；同时检查服务额度和网络连接。

**打开历史翻译会再次调用模型吗？**

不会。打开已保存的翻译直接展示本地结果；重新查词使用当前导入的词典。
